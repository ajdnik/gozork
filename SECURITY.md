# Security Policy

## Supported Versions

Only the latest version on the `main` branch is supported with security updates.

| Version | Supported          |
|---------|--------------------|
| main    | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly using
[GitHub's private vulnerability reporting](https://github.com/ajdnik/gozork/security/advisories/new).

**Please do not open a public issue for security vulnerabilities.**

### What to expect

- **Acknowledgment** within 48 hours of your report.
- **Status update** within 7 days with an assessment and expected timeline.
- **Resolution** within 90 days for confirmed vulnerabilities.

### Scope

This is an educational game project (a Go port of Zork I). The attack surface is limited,
but reports about any security issue are welcome, including:

- Memory safety issues
- Input handling bugs
- CI/CD pipeline vulnerabilities
- Dependency concerns
